# Brain Dump Organizer

Transform a stream-of-consciousness dump into an actionable, categorized system.

## When to use

- Turn a chaotic brain dump into an organized format of tasks, projects, someday/maybe, and next actions. Use when asked to organize a brain dump, sort messy ideas, or structure scattered thoughts.

## Workflow

1. Read the entire dump without judgment - capture everything.
2. Classify each item: actionable task, project (needs multiple steps), someday/maybe, reference, or discard.
3. For tasks: identify the next action and context.
4. For projects: note the project name and first step.
5. Group and deduplicate overlapping items.
6. Present a clean structure: Tasks / Projects / Someday-Maybe / Notes.

## Output format

Organized output grouped into Tasks, Projects, Someday/Maybe, and Reference.

## Constraints

- Do not discard items silently - keep everything, even if parked.
- Do not invent deadlines; leave dates out unless given.
