# Convert Notes into Teaching Script

Turn notes into a spoken teaching script: logical flow, clear explanations, natural spoken language.

## When to use

- Transform notes into a clear, structured teaching script. Use when asked to create a teaching script, lesson script, or presentation script from notes.

## Workflow

1. Read the notes and define the learning objective.
2. Sequence the content for learning: context, concept, examples, practice, recap.
3. Write in spoken language - short sentences, natural phrasing, transition words.
4. Add verbal cues for the instructor (pause, emphasize, ask question).
5. Include example explanations and likely student questions.
6. Close with a summary and a check for understanding.

## Output format

A teaching script with sections, speaking cues, and examples.

## Constraints

- Content must stay accurate to the source notes.
- Script should be speakable aloud in a natural rhythm.
