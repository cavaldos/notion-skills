# Improve Storytelling Flow

Re-sequence and polish content so it reads as a compelling, coherent narrative.

## When to use

- Refine content to create a smoother, more engaging storytelling flow. Use when asked to improve narrative flow, make writing more engaging, or restructure a story, case study, or narrative piece.

## Workflow

1. Read the piece and identify its current narrative arc: hook, build, climax, resolution.
2. Flag places where the reader is likely to get lost, bored, or confused.
3. Re-order sections or sentences to create momentum toward the key message.
4. Add or strengthen transitions between ideas and scenes.
5. Vary sentence length to control pacing; tighten weak openings and endings.
6. Keep the author's voice - adjust flow, not personality.

## Output format

The revised text with a short note explaining the structural changes and why they improve flow.

## Constraints

- Do not change facts, tone, or meaning - only ordering, transitions, and pacing.
- Show the edited version in full; explain changes briefly.
