# Remove AI Fingerprint

Rewrite AI-generated text so it reads naturally human: kill clichés, forced structures, and robotic cadence.

## When to use

- Strip the AI fingerprint from any text - remove telltale AI phrasing, structure, and word choices. Use when asked to make text sound human, de-AI text, or remove AI-sounding language.

## Workflow

1. Identify AI tells: 'delve', 'tapestry', 'em dash floods', 'In conclusion', 'Furthermore', 'It's worth noting', overly parallel structure, generic hedging.
2. Rewrite those phrases in natural, varied language.
3. Break the rigid structure: vary paragraph lengths and sentence rhythm.
4. Add specificity - concrete details or asides where appropriate (only from existing content).
5. Remove redundant qualifiers and over-explanation.
6. Read aloud in your head; if it sounds like an essay generator, fix it.

## Output format

The rewritten text with the AI fingerprint removed, meaning intact.

## Constraints

- Do not invent new facts or details - humanize style, not content.
- Keep the user's voice: if the user provides style samples, match them.
