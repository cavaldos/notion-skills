# Turn Tasks into Timeline

Convert a task list into a clear, ordered timeline.

## When to use

- Turn tasks into a clear timeline. Use when asked to create a timeline from tasks, schedule tasks, or build a project timeline.

## Workflow

1. Collect all tasks with any known durations and deadlines.
2. Identify dependencies between tasks.
3. Estimate durations for tasks missing them (mark as estimates).
4. Sequence tasks: critical path first, parallelize independent work.
5. Present the timeline with dates or relative order.

## Output format

A timeline: ordered tasks with durations, dependencies, and dates.

## Constraints

- Mark estimated durations clearly - do not present guesses as facts.
- Flag impossible deadlines rather than silently compressing.
