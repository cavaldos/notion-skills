# Prioritize Tasks

Rank a list of tasks by importance and urgency so effort goes where it matters.

## When to use

- Prioritize tasks based on importance and urgency. Use when asked to prioritize tasks, rank to-dos, or decide what to work on first.

## Workflow

1. Collect the full task list and any deadlines or dependencies.
2. Score each task on importance (impact of doing it) and urgency (time sensitivity).
3. Sort into quadrants: urgent+important, important not urgent, urgent not important, neither.
4. Suggest an order of execution and what to defer or drop.
5. Note any dependencies that force a particular sequence.

## Output format

A prioritized task list with rationale and suggested execution order.

## Constraints

- Rank based on provided information; ask about missing context if needed.
- Be decisive - avoid wishy-washy ties without reasoning.
