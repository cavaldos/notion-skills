# TCF Écrit — Tâche 1 : Message court

Write model answers for **Tâche 1** of the TCF Expression Écrite: rédaction d'un message pour décrire, raconter et/ou expliquer, adressé à un ou plusieurs destinataires dont le statut est précisé dans la consigne.

## Non-negotiable Exam Rules

- **Length: 60 mots minimum / 120 mots maximum.** Target **90–110 mots** in models — comfortably above minimum, never at the ceiling.
- FEI word counting: *1 mot = tout ensemble de signes placé entre deux espaces*. So `C'est-à-dire` = 1 word, `l'école` = 1 word, `Un bon sujet` = 3 words. Count this way before delivering.
- **Do all tasks in order** in real exams; never leave blank; never recopy sentences from the consigne (recopying risks « A1 non atteint »).
- Off-topic or wrong length can zero the whole production. State the final word count in your answer.

## Register Decision (first step)

Identify the destinataire from the consigne:

| Destinataire | Register | Pronoun | Appel | Clôture |
| --- | --- | --- | --- | --- |
| Ami(e), famille, proche | familier | `tu` | `Salut Marie,` `Coucou !` `Cher Paul,` | `Bises,` `Amitiés,` `À bientôt,` `Gros bisous` |
| Collègue connu | courant | `tu`/`vous` | `Bonjour Marc,` | `À plus tard,` `Cordialement,` |
| Inconnu, administration, service client | formel/courant soigné | `vous` | `Madame, Monsieur,` `Bonjour,` | `Cordialement,` `Merci d'avance,` |

Register mistakes cost more than grammar mistakes here — mismatched `tu/vous` or `Bises` to a stranger reads as sociolinguistic failure.

## Structure Template (~5 blocks)

1. **Appel** (not counted against content): `Salut Léa,`
2. **Accroche contextuelle** (1 sentence): react to the situation — `Merci encore pour ta carte !` / `J'espère que tu vas bien.`
3. **Corps = TOUS les points de la consigne**, one short paragraph each. The consigne almost always lists 2–4 required points (décrire + raconter + expliquer...). Tick every single one; a missed point caps the score on respect de la consigne.
4. **Clôture conversationnelle** (1 sentence): question back or wish — `Et toi, qu'est-ce que tu as prévu ?` / `Réponds-moi vite, s'il te plaît !`
5. **Formule de congé**: per register table.

## Language Targets (stable B1+/B2)

- Narration: **passé composé** for events (`j'ai perdu ma valise`), **imparfait** for descriptions/background (`il faisait beau`, `la valise était bleue`) — mixing them correctly is the main grammar signal.
- Plans: `futur proche` (`je vais organiser une fête`) and `futur simple` (`nous partirons en juillet`).
- Precision details when relevant: colors, sizes, prices, dates, times (`un vélo gris, taille M, acheté 200 € l'an dernier`).
- Polite requests if needed: `Pourriez-vous me rembourser ?` / `Je voudrais savoir si...`.
- Avoid repeating `très` everywhere; use `vraiment`, `super`, `tellement` sparingly (register-appropriate).

## Recurring Consigne Types (from the user's bank)

- Vacances : où / météo / hôtel / activités → PC+imparfait mix.
- Événement personnel : anniversaire et cadeaux reçus, déménagement et raisons.
- Invitation (`faire le pont`) : remercier, accepter, proposer d'apporter quelque chose.
- Vente entre particuliers : décrire l'objet, état, prix, proposer un rendez-vous.
- Réclamation service client : décrire le problème factuellement, demander échange ou remboursement.
- Fête à organiser : lieu, date, heure, menu, prix, demander confirmation RSVP.

## Workflow

1. Read the consigne; list its required points as a checklist.
2. Decide register (table above).
3. Draft the model answer hitting every point, then **count words** (FEI rule); adjust to land inside 90–110.
4. Deliver:
   - The model answer (French only).
   - Word count line: `~X mots`.
   - Vietnamese study notes: 3–6 collocations/structures worth memorizing (`faire la fête`, `être au chômage`, `rendre service à qqn`) + one grammar focus of the day.
   - Optional outline mapping which sentence covers which consigne point.
5. If the user provides their own draft instead, switch to the `tcf-writing-review` skill rather than rewriting silently.

## Quality Bar

- Every consigne point is visibly covered — a reader can tick them off.
- Register is consistent start to finish (no `Salut` + `je vous prie d'agréer` mixes).
- No sentence is copied from the prompt.
- Length inside limits, reported honestly using FEI counting.
