# Compare Concepts

Produce a clear side-by-side comparison of two or more concepts.

## When to use

- Compare concepts clearly and side by side. Use when asked to compare two things, contrast concepts, or create a comparison.

## Workflow

1. Identify the concepts and the comparison dimensions that matter.
2. Define 3-7 meaningful dimensions (definition, pros, cons, use cases, cost...).
3. Fill each dimension for each concept based on the source material.
4. Highlight key differences and when to choose which.
5. Present as a table or structured side-by-side.

## Output format

A side-by-side comparison (table or structured) with a 'choose when' note.

## Constraints

- Only use information available or verified - no invented facts.
- Dimensions must be the same for all compared concepts.
