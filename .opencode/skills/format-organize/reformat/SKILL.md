# Reformat

Restructure raw or messy content into clean, scannable formatting while preserving every original word.

## When to use

- Clean up messy text and formatting without changing the writing - organize headings, paragraphs, lists, checklists, tables, and spacing, and remove artifacts like duplicates and stray characters. Use when asked to reformat, tidy, organize, or structure messy documents or notes.

## Workflow

1. Analyze the text: parse into blocks (headings, paragraphs, lists, checklists, tables) and identify the logical structure.
2. Remove artifacts: duplicate lines, stray characters, formatting junk, placeholders - note anything removed.
3. Assign a logical heading hierarchy (H1/H2/H3) matching the content; split paragraph walls into headings, bullets, and short paragraphs.
4. Convert appropriate content into bullets, numbered lists, or checklists; convert tabular data into markdown tables.
5. Normalize list styles, heading levels, and spacing between blocks.
6. Verify: every original word still present, in original order; check the result scans well.

## Output format

A clean, professionally formatted document preserving 100% of the original wording.

## Constraints

- Word-for-word preservation is mandatory - this skill formats, never edits.
- Do not invent headings that misrepresent content.
- Do not delete information that may matter; summarize any removals.
