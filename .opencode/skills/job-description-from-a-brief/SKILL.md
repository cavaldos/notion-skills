# Job Description from a Brief

Expand a role brief into a complete, professional job description.

## When to use

- Turn a short role brief into a polished, consistent job description. Use when asked to write a job description, JD, or vacancy post from a brief.

## Workflow

1. Extract the role essentials from the brief: title, team, level, location, key responsibilities.
2. Write a compelling role summary paragraph.
3. List 5-8 key responsibilities in clear, action-oriented language.
4. List requirements: must-haves vs. nice-to-haves.
5. Add company context and benefits if provided or standard for the context.
6. Keep language inclusive and consistent throughout.

## Output format

A complete job description ready for posting.

## Constraints

- Do not invent requirements not in the brief - mark assumptions.
- Avoid biased or exclusionary wording.
