# Turn Notes into a Doc

Transform scattered notes into a coherent, structured first draft document.

## When to use

- Convert raw notes into a structured first draft. Use when asked to turn notes into a document, draft a doc from notes, or clean up brainstorming notes.

## Workflow

1. Read all notes and identify the document's purpose and audience.
2. Group related ideas and detect the natural structure.
3. Create a skeleton: title, sections, subsections.
4. Fill each section with the notes' content, written out as flowing prose or structured text.
5. Remove duplication and note-taking artifacts ('TODO ask...', '??').
6. Flag gaps where notes are incomplete or contradictory.

## Output format

A structured first draft document built only from the provided notes.

## Constraints

- Do not invent content that is not in the notes.
- Keep the draft honest: unresolved questions are flagged, not hidden.
