# ELI5 (Explain Like I'm 5)

Explain a concept using plain language, analogies, and zero assumed background knowledge.

## When to use

- Rewrite content so a brand-new joiner can follow it without prior context. Use when asked to explain like I'm 5, simplify for beginners, or make content accessible to newcomers.

## Workflow

1. Identify the core concept and any jargon or assumptions in the source text.
2. Define every technical term in plain words before using it.
3. Choose one strong analogy from everyday life that maps to the concept.
4. Explain step by step, building from a single simple idea to the full concept.
5. Check each sentence: would a newcomer with no context understand it? If not, simplify.

## Output format

A plain-language explanation with: one-sentence summary, analogy, step-by-step breakdown, glossary of terms used.

## Constraints

- Max 2 short paragraphs plus the analogy - brevity is the point.
- Never silently drop important nuance; simplify language, not facts.
