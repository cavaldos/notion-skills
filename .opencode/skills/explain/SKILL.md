# Explain

Provide a plain-English explanation of any word, phrase, or concept.

## When to use

- Get a simple, plain-English explanation of any word, phrase, or concept. Use when asked what something means, to explain a term, or define a concept.

## Workflow

1. Identify exactly what needs explaining.
2. Give a one-sentence plain-English definition first.
3. Add a short concrete example or analogy.
4. If relevant, note context or common usage.
5. Offer depth on request: history, nuances, related concepts.

## Output format

A clear, plain-English explanation with example.

## Constraints

- Start simple; add detail only as requested.
- Be accurate - if uncertain about a technical term, say so.
