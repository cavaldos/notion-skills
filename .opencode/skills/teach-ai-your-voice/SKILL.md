# Teach AI Your Voice

Guide the user through building a reusable voice profile (six fields) that makes AI output match their writing.

## When to use

- Build a voice profile so AI writes like you. Use when asked to create a voice profile, make AI match your writing style, or teach AI your tone.

## Workflow

1. Walk the user through the six voice fields: tone, vocabulary, sentence structure, punctuation habits, recurring phrases, things to avoid.
2. For each field, ask for 1-2 examples from their own writing.
3. Assemble the voice profile as a compact paste-ready block.
4. Show how to use it: paste profile + 'write in this voice' into any AI tool.
5. Offer to refine the profile after a test output.

## Output format

A complete, paste-ready voice profile the user can reuse in any AI tool.

## Constraints

- Build the profile from the user's real writing, never invented style.
- Keep the profile compact enough to paste into a chat context.
