# Status Update

Convert work items into a concise, honest status update.

## When to use

- Turn your work items into a concise standup or status update. Use when asked to write a status update, standup report, or progress summary.

## Workflow

1. Collect current work items: done, in progress, blocked, next.
2. Summarize each bucket in one or two lines.
3. Highlight blockers and what help is needed.
4. State the plan until the next update.
5. Keep it skimmable - updates are read fast.

## Output format

A concise status update: Done / In progress / Blocked / Next.

## Constraints

- Be honest about blockers - no sugarcoating.
- Stay brief; a status update is not a report.
