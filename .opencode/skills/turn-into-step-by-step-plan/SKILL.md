# Turn into Step-by-Step Plan

Convert an idea or goal into an ordered, step-by-step action plan.

## When to use

- Turn ideas into a step-by-step plan. Use when asked to create a step-by-step plan, break something into steps, or make an actionable procedure.

## Workflow

1. Clarify the end state the plan must achieve.
2. List everything that must happen to get there.
3. Order steps by dependency and sequence.
4. Add decision points and prerequisites.
5. Define how to know each step is done.

## Output format

An ordered step-by-step plan with completion criteria.

## Constraints

- Every step must be concrete and actionable.
- Flag unknown prerequisites instead of skipping them.
