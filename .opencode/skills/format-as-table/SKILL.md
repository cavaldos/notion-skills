# Format as Table

Convert loose text or bullet lists into a clean, well-structured table.

## When to use

- Convert loose text or bullets into a clean, structured table. Use when asked to format content as a table, tabulate data, or create a comparison table.

## Workflow

1. Identify the data fields from the text (columns).
2. Define the table columns that capture the data cleanly.
3. Map each item to a row, filling every column.
4. Normalize cell values: consistent units, casing, formats.
5. Mark cells with no data as '—' or 'N/A' explicitly.

## Output format

A clean markdown table with consistent rows and columns.

## Constraints

- Do not invent data to fill empty cells.
- Choose column names that match the source's terms.
