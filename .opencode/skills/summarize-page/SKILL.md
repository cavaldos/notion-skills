# Summarize Page

Produce a clear, accurate summary of a full page or selection.

## When to use

- Summarize a page, document, or selection. Use when asked to summarize a page, get the gist of a document, or create a TL;DR.

## Workflow

1. Read the entire page and identify the main topic and purpose.
2. Extract the key points, arguments, and conclusions.
3. Note any data, decisions, or action items that matter.
4. Write a summary that scales with the user's request: TL;DR (1-2 lines), short (bullet points), or detailed (structured).
5. Verify every claim in the summary appears in the original.

## Output format

A concise summary with the requested level of detail.

## Constraints

- Never include information not in the source.
- Preserve the relative emphasis of the original.
