# Translate

Translate any content into a target language, preserving meaning, tone, and formatting.

## When to use

- Translate content into another language while preserving tone and meaning. Use when asked to translate text into a specific language.

## Workflow

1. Confirm the target language (and dialect/register if relevant).
2. Read the full source for meaning and tone.
3. Translate meaning-first, adapting idioms and cultural references.
4. Preserve formatting: headings, lists, tables, emphasis.
5. Re-read the translation in the target language for naturalness.
6. Verify accuracy and tone match the original.

## Output format

Full translation in the target language.

## Constraints

- Preserve numbers, dates, names, and technical terms correctly.
- Match the source register; do not make formal text casual.
