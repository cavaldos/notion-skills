# Translate

Produce a natural, accurate translation that preserves meaning, tone, register, and formatting.

## When to use

- Translate content into a target language (including English) while preserving meaning, tone, register, and formatting. Use when asked to translate text, translate to English, or convert content into another language.

## Workflow

1. Confirm the target language (and dialect/register if relevant); default to English if unspecified.
2. Read the full source to capture meaning, tone, and register.
3. Translate meaning-for-meaning, not word-for-word; adapt idioms and cultural references to natural equivalents.
4. Preserve formatting: headings, lists, tables, emphasis; keep proper nouns, brands, and standard terms untranslated.
5. Re-read the translation for flow and naturalness in the target language.
6. Verify accuracy, tone, and register match the original.

## Output format

Full translation in the target language with original formatting preserved.

## Constraints

- Preserve numbers, dates, names, and technical terms correctly.
- Match the source register; do not make formal text casual or casual text formal.
- Do not paraphrase away important details.
