# SOP from a Process Description

Transform a process description into a clear, repeatable standard operating procedure.

## When to use

- Turn a described process into a clear, repeatable SOP. Use when asked to create an SOP, standard operating procedure, or process documentation from a description.

## Workflow

1. Map the process from start to finish, noting each step.
2. Structure the SOP: Purpose, Scope, Prerequisites, Step-by-step procedure, Quality checks, Escalation.
3. Write each step as a clear action, with who does it and any inputs/outputs.
4. Add decision points and error handling.
5. Define how to verify the process worked (quality checks).

## Output format

A complete SOP document with numbered steps and quality checks.

## Constraints

- Only document what the description supports - flag gaps.
- Write so a new person could execute it without asking.
