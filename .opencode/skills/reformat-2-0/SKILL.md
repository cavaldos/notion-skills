# Reformat 2.0

Advanced formatting pass that organizes all block types while preserving every word exactly.

## When to use

- Clean up messy text without changing your writing - organize headings, paragraphs, lists, checklists, tables, and spacing. Use when asked to reformat, tidy, or structure messy documents.

## Workflow

1. Parse the text into blocks: headings, paragraphs, lists, checklists, tables.
2. Assign a logical heading hierarchy (H1/H2/H3) matching the content.
3. Split or merge paragraphs so each contains one idea.
4. Convert appropriate content into bullets, numbered lists, or checklists.
5. Convert tabular data into markdown tables.
6. Normalize spacing between blocks for readability.
7. Verify: every original word still present, in original order.

## Output format

A clean, professionally formatted document preserving 100% of the original words.

## Constraints

- Word-for-word preservation is mandatory - this skill formats, never edits.
- Do not add, remove, or reorder any written content.
