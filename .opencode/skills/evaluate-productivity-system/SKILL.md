# Evaluate Productivity System

Assess a productivity system against best practices and the user's goals.

## When to use

- Evaluate a productivity system. Use when asked to review a productivity system, assess a workflow setup, or evaluate GTD/kanban/task system health.

## Workflow

1. Understand the system's components (capture, organize, execute, review).
2. Check each component: is it working, populated, and current?
3. Identify leaks: where tasks, ideas, or commitments slip.
4. Compare against the user's stated goals and workload.
5. Recommend concrete fixes: simplify, automate, or drop parts.

## Output format

An evaluation with strengths, leaks, and prioritized fixes.

## Constraints

- Base the evaluation on the user's actual system - ask what it looks like.
- Recommendations must be practical, not ideal-world.
