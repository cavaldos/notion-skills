# Reformat

Restructure raw or messy content into clean, scannable formatting.

## When to use

- Clean up formatting to make content structured and easy to scan. Use when asked to reformat, organize messy text, or improve a document's structure.

## Workflow

1. Analyze the text's logical structure: main sections, subsections, lists, tables.
2. Convert paragraph walls into headings, bullets, and short paragraphs.
3. Normalize list styles, headings levels, and spacing.
4. Keep all original wording and facts intact.
5. Check the result scans well: reader should grasp key points in seconds.

## Output format

Reformatted document with clean headings, lists, and spacing - same words, better structure.

## Constraints

- Never edit wording, only formatting and structure.
- Do not invent headings that misrepresent content.
