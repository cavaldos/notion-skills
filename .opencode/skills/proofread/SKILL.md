# Proofread

Catch and fix mechanical errors and minor awkwardness while leaving meaning untouched.

## When to use

- Tighten and correct a selection or page without changing its meaning. Use when asked to proofread, check for typos, fix grammar, or review a text for errors.

## Workflow

1. Read the text once to understand it fully.
2. Fix spelling, grammar, and punctuation errors.
3. Correct typos, duplicate words, and spacing issues.
4. Tighten obviously clumsy phrasing only where meaning is unaffected.
5. Re-read the corrected version against the original to verify zero meaning drift.

## Output format

Corrected text (or a list of specific corrections if the user prefers a diff-style review).

## Constraints

- Mechanical corrections only - do not rewrite style, tone, or structure.
- Flag anything suspicious (possible factual error, missing word) instead of guessing.
