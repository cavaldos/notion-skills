# Proofread

Catch and fix mechanical errors and minor awkwardness while leaving meaning, tone, and structure untouched.

## When to use

- Catch and fix mechanical errors - spelling, grammar, punctuation, typos - and repair genuinely broken or unclear sentences without changing meaning or style. Use when asked to proofread, check for typos, fix grammar, correct a text, or review a text for errors.

## Workflow

1. Read the text once to understand it fully.
2. Fix spelling, grammar, and punctuation errors.
3. Correct typos, duplicate words, and spacing issues.
4. Repair ambiguous or broken sentences for clarity, keeping the author's voice and structure.
5. Tighten obviously clumsy phrasing only where meaning is unaffected.
6. Re-read the corrected version against the original to verify zero meaning drift.

## Output format

Corrected text (or a list of specific corrections if the user prefers a diff-style review).

## Constraints

- Mechanical corrections only - do not rewrite style, tone, or structure.
- Only touch sentences that are genuinely broken or unclear.
- Flag anything suspicious (possible factual error, missing word) instead of guessing.
