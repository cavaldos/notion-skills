# Extract Key Ideas

Pull out the key ideas from any content in a clean list.

## When to use

- Extract key ideas from content. Use when asked to extract key ideas, pull main concepts, or list the important points of a text.

## Workflow

1. Read the content fully to understand the argument.
2. Identify the core ideas that the content stands on.
3. Distinguish key ideas from examples, evidence, and tangents.
4. Express each idea as a clear standalone statement.
5. Order ideas by importance or logical flow.

## Output format

A clean list of key ideas.

## Constraints

- Keep ideas faithful to the source - no reinterpretation.
- Aim for the essential few, not an exhaustive dump.
