# Headline Options

Produce multiple headline options, ranked by effectiveness, for any piece of content.

## When to use

- Generate a ranked set of headline or title options to choose from. Use when asked for headline ideas, title options, or catchy titles for content.

## Workflow

1. Understand the content's core message and target audience.
2. Generate a diverse set of headlines: benefit-driven, curiosity-driven, direct, question-based, numbers-based.
3. Rank them by expected performance: clarity, specificity, curiosity gap, length.
4. Explain briefly why the top picks work.
5. Offer variations on the best options (different lengths/tone).

## Output format

A ranked list of 8-12 headline options with short rationale for the top ones.

## Constraints

- Headlines must be honest - no clickbait that the content cannot deliver.
- Match the brand's tone and platform norms.
