# Summarize 2.0

Advanced summarization that extracts key ideas, decisions, action items, and conclusions with adaptive formatting.

## When to use

- Summarize long content into clear, actionable insights - extract key ideas, decisions, action items, and conclusions. Use when asked for an advanced summary, actionable summary, or insights from content.

## Workflow

1. Read the content and identify its type (article, meeting notes, email, spec...).
2. Extract: key ideas, decisions made, action items (with owners/dates if present), conclusions.
3. Adapt the output format to the content type (e.g., meeting → recap structure).
4. Preserve important context so insights remain usable.
5. Verify all extractions trace to the source.

## Output format

A structured summary: Key Ideas, Decisions, Action Items, Conclusions - formatted for the content type.

## Constraints

- Distinguish facts from interpretation.
- Do not invent action items or owners.
