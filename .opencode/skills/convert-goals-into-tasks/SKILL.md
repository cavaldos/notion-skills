# Convert Goals into Tasks

Decompose high-level goals into concrete, actionable tasks.

## When to use

- Convert goals into actionable tasks. Use when asked to turn goals into tasks, break goals into actions, or make goals executable.

## Workflow

1. Clarify each goal and its definition of done.
2. Break each goal into milestones.
3. Identify the concrete tasks that achieve each milestone.
4. Assign owners and rough order where relevant.
5. Check: can each task be acted on today?

## Output format

A goal-to-task breakdown: goal → milestones → actionable tasks.

## Constraints

- Every task must directly serve its goal - no busywork.
- Keep tasks concrete and unambiguous.
