# Break Project into Phases

Decompose a project into logical, well-defined phases.

## When to use

- Break projects into structured phases. Use when asked to phase a project, create project phases, or structure a project roadmap.

## Workflow

1. Understand the project's end goal and scope.
2. Identify natural phase boundaries (milestones, deliverables, gates).
3. Define each phase: goal, deliverables, exit criteria.
4. Order phases by dependency and value.
5. Note what each phase needs to start (inputs).

## Output format

A phased project plan: phases with goals, deliverables, and exit criteria.

## Constraints

- Phases must be sequential and buildable in reality.
- Keep exit criteria concrete and checkable.
