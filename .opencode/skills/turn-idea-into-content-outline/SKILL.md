# Turn Idea into Content Outline

Turn a raw idea into a structured, buildable content outline.

## When to use

- Convert an idea into a structured content outline. Use when asked to outline content from an idea, create a content structure, or plan an article/video outline.

## Workflow

1. Clarify the idea, format (article, video, course), and audience.
2. Define the core message and desired takeaway.
3. Brainstorm the sections that deliver the message.
4. Order sections logically; add key points per section.
5. Add hook, transitions, and CTA/conclusion notes.

## Output format

A structured content outline: hook, sections with key points, conclusion.

## Constraints

- Outline must be faithful to the idea - no scope creep.
- Keep each section's points concrete.
