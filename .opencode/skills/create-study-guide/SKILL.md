# Create Study Guide

Turn content into a structured study guide optimized for learning.

## When to use

- Organize content into a structured study guide for efficient learning. Use when asked to create a study guide, exam prep material, or organize content for learning.

## Workflow

1. Identify the material and the learning goals.
2. Structure: key concepts, definitions, formulas, examples, practice questions.
3. Condense content into digestible, scannable sections.
4. Add mnemonics or memory aids where helpful.
5. Include self-check questions per section.

## Output format

A structured study guide with concepts, examples, and self-checks.

## Constraints

- Stay faithful to the source material.
- Prioritize the most test-relevant content.
