# Proposal Draft

Assemble scope inputs into a professional, structured proposal or statement of work.

## When to use

- Turn scope inputs into a structured proposal or SOW. Use when asked to draft a proposal, SOW, or statement of work from scope inputs.

## Workflow

1. Gather scope inputs: objectives, deliverables, timeline, budget, constraints.
2. Structure the proposal: executive summary, context, scope, deliverables, timeline, pricing, terms.
3. Write each section clearly, converting bullet inputs into polished prose where appropriate.
4. Define deliverables and success criteria explicitly.
5. Flag missing information (pricing, dates) as placeholders rather than inventing.

## Output format

A complete proposal/SOW draft with clear sections.

## Constraints

- Never invent numbers - mark placeholders for the user to fill.
- Keep language professional and unambiguous.
