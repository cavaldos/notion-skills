# Extract Action Items

Extract every action item from notes into a clean, owned, dated checklist.

## When to use

- Pull a clear, owned, dated checklist of action items out of any notes. Use when asked to extract action items, find actionables, or list to-dos from notes.

## Workflow

1. Read the notes and identify every actionable statement.
2. For each: state the action, infer/note the owner, and capture any date.
3. Reject non-actionable content (context, decisions without action).
4. Order by due date or priority where known.
5. Mark action items with missing owner or date.

## Output format

A checklist of action items: action, owner, due date.

## Constraints

- Do not invent owners or dates - mark them as unknown.
- Include only actions actually present in the notes.
