# Create Workflow from Notes

Turn notes into a clear, repeatable workflow diagram or step flow.

## When to use

- Create workflows from notes. Use when asked to build a workflow from notes, design a process, or turn notes into a repeatable flow.

## Workflow

1. Read the notes and identify the process's start and end.
2. Extract every step and decision point.
3. Order steps and connect decisions to branches.
4. Define inputs, outputs, and owners per step.
5. Present as a numbered flow or diagram (e.g., mermaid).

## Output format

A workflow: steps, decision points, branches, owners - in flow format.

## Constraints

- The workflow must reflect the notes, not an idealized process.
- Flag ambiguous steps rather than inventing them.
