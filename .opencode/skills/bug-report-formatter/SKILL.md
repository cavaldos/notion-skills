# Bug Report Formatter

Convert messy bug notes into a structured, actionable bug report.

## When to use

- Turn a freeform bug note into a clean, structured report engineers can act on. Use when asked to format a bug report, structure bug notes, or write a proper bug ticket.

## Workflow

1. Extract the core issue from the freeform notes.
2. Structure: Summary, Environment, Steps to reproduce, Expected vs Actual, Impact, Severity.
3. Fill each field with the information present; mark gaps as unknown.
4. Separate observed facts from user interpretation.
5. Keep language neutral and precise.

## Output format

A structured bug report with standard fields.

## Constraints

- Do not invent reproduction steps or technical details.
- Mark missing info explicitly - engineers hate guessing.
