# Improve Writing 2.0

Advanced polish pass: grammar, readability, sentence flow, and clarity while preserving meaning, tone, and style.

## When to use

- Make writing clearer, smoother, and more professional without changing voice. Use when asked to improve writing quality, polish a draft, or fix grammar/readability/clarity while keeping the author's style.

## Workflow

1. Pass 1 - Correct: fix grammar, punctuation, and spelling.
2. Pass 2 - Clarity: rewrite ambiguous or overloaded sentences; one idea per sentence.
3. Pass 3 - Flow: improve transitions and sentence rhythm; vary structure.
4. Pass 4 - Professionalism: remove casual filler and weak qualifiers without flattening voice.
5. Pass 5 - Verify: re-read against the original; confirm meaning, tone, and style survived.

## Output format

The full revised text, followed by a brief change-log of the main improvements.

## Constraints

- Preserve the author's voice and original meaning - this is the core requirement.
- Do not inflate the text; if nothing needs changing, say so.
