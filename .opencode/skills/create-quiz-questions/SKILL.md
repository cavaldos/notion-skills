# Create Quiz Questions

Generate effective quiz questions from content or a topic.

## When to use

- Generate quiz questions from provided content or topics. Use when asked to create quiz questions, make a quiz, or generate assessment questions.

## Workflow

1. Identify the material the quiz covers and the level (beginner/advanced).
2. Draft questions that test understanding, not just recall (where possible).
3. Provide multiple-choice options with one correct answer, or open questions with model answers.
4. Add brief explanations for the correct answer.
5. Vary question types and difficulty.

## Output format

A quiz: questions, options, correct answers, and explanations.

## Constraints

- Questions must be answerable from the provided material.
- No trick questions or ambiguous options.
