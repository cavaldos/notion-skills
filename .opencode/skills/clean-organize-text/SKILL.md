# Clean & Organize Text

Remove noise and structure scattered content into a clean, organized form.

## When to use

- Clean and organize messy text. Use when asked to clean up text, organize scattered notes, or tidy messy content.

## Workflow

1. Remove artifacts: duplicate lines, stray characters, formatting junk, placeholders.
2. Identify the logical groups and hierarchy in the content.
3. Organize into sections with headings and lists.
4. Normalize inconsistent formatting and casing.
5. Keep all meaningful content; note anything removed.

## Output format

Cleaned, organized text with clear structure.

## Constraints

- Do not delete information that may matter - summarize removals.
- Preserve original wording of the kept content.
