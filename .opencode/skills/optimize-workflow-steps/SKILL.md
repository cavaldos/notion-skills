# Optimize Workflow Steps

Identify and apply improvements to make a workflow faster, cheaper, or higher quality.

## When to use

- Optimize workflow steps. Use when asked to optimize a workflow, streamline steps, or make a process more efficient.

## Workflow

1. Map the current workflow steps and their costs (time, effort, failure rate).
2. Identify waste: duplication, waiting, unnecessary steps, manual work.
3. Propose optimizations: merge, remove, automate, parallelize, reorder.
4. Check each optimization against constraints (quality, compliance).
5. Present a before/after workflow with expected impact.

## Output format

An optimized workflow with before/after comparison and expected gains.

## Constraints

- Optimizations must not break required outcomes.
- Be specific about what changes and why.
