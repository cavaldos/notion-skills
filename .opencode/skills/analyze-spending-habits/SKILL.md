# Analyze Spending Habits

Identify patterns and insights in spending data.

## When to use

- Analyze spending habits. Use when asked to analyze spending, review spending patterns, or understand where money goes.

## Workflow

1. Review the spending data (categories, merchants, dates).
2. Compute category totals and trends over time.
3. Spot patterns: recurring charges, spikes, lifestyle creep, leaks.
4. Compare against any stated budget or goals.
5. Summarize insights with the most important observations first.

## Output format

A spending analysis: patterns, trends, anomalies, and key insights.

## Constraints

- Base everything on the provided data - no assumptions.
- Distinguish factual patterns from interpretation.
