# Turn Notes into Summary

Convert raw notes into a clean, clear summary.

## When to use

- Turn notes into a clear summary. Use when asked to summarize notes, create a summary from notes, or condense meeting/class notes.

## Workflow

1. Read the notes and identify the core themes.
2. Remove duplication, fillers, and note-taking shorthand.
3. Organize the remaining content under clear headings.
4. Write flowing summary sentences for each section.
5. Highlight decisions, action items, and open questions if present.

## Output format

A clear, organized summary derived from the notes.

## Constraints

- Do not add information beyond the notes.
- Keep it concise but complete.
