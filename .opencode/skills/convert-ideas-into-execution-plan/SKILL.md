# Convert Ideas into Execution Plan

Turn a raw idea into a concrete, step-by-step execution plan.

## When to use

- Convert ideas into an execution plan. Use when asked to turn an idea into a plan, create an execution roadmap, or plan how to make an idea real.

## Workflow

1. Clarify the idea and its desired outcome.
2. Break the outcome into major milestones.
3. Define the concrete steps and tasks within each milestone.
4. Identify dependencies, owners, and rough order of work.
5. Note risks, unknowns, and what to validate first.
6. Define success criteria for the first milestone.

## Output format

An execution plan: milestones, tasks, dependencies, owners, risks, success criteria.

## Constraints

- Keep the plan actionable - every step should be executable by someone.
- Flag assumptions rather than presenting them as facts.
