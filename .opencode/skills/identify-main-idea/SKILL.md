# Identify Main Idea

Extract the single most important idea a text is trying to convey.

## When to use

- Identify the main idea of any text. Use when asked for the main idea, key message, or central point of a text.

## Workflow

1. Read the entire text to absorb full context.
2. Ask: what is this text fundamentally trying to say?
3. Distinguish the main idea from supporting evidence and tangents.
4. Express the main idea in one clear sentence.
5. Optionally list 2-4 supporting points that back the main idea.

## Output format

One-sentence main idea, plus optional supporting points.

## Constraints

- The main idea must be grounded in the text, not inferred wildly.
- One sentence - if it takes more, it is not the main idea.
