# Turn into Checklist

Convert any content into a clean, actionable checklist.

## When to use

- Turn content into a checklist. Use when asked to convert content into a checklist, todo list, or step-by-step verification list.

## Workflow

1. Read the content and extract all actionable items.
2. Order items logically: sequence or priority.
3. Phrase each item as a checkable action (verb-first).
4. Group related items under headings if the list is long.
5. Exclude non-actionable content (context, reasoning).

## Output format

A clean checklist with checkable items, grouped if needed.

## Constraints

- Every checklist item must be objectively checkable.
- Do not lose important steps from the source.
