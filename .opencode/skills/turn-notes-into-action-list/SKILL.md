# Turn Notes into Action List

Convert notes into a clean list of concrete actions.

## When to use

- Turn notes into a clear action list. Use when asked to convert notes into actions, list next steps from notes, or make notes actionable.

## Workflow

1. Read the notes and identify everything that requires action.
2. Phrase each item as a clear action (verb-first).
3. Group or order by context, priority, or deadline if present.
4. Discard non-actionable content (record it as reference).
5. Present the action list cleanly.

## Output format

A clear action list derived from the notes.

## Constraints

- Only actions grounded in the notes.
- Keep items specific enough to execute.
